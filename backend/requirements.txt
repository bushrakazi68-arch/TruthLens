# TruthLens backend dependencies - the FULL set (laptop, or a host with ~1 GB+ RAM).
#
# Everything in requirements-base.txt plus PyTorch Geometric. With these
# installed the spread predictor assembles its propagation graph as a PyG `Data`
# object; without them it uses plain arithmetic and returns the same numbers.
#
# The Docker image installs only requirements-base.txt by default (PyTorch adds
# ~225 MB of memory, which does not fit the free hosting tiers). To build the
# full image on a bigger host:
#
#     docker build --build-arg WITH_TORCH=1 .
#
# Must be saved as UTF-8 - a UTF-16 file cannot be parsed by pip on Linux.

-r requirements-base.txt

# ── Spread graph assembly (optional at runtime) ──────────────
