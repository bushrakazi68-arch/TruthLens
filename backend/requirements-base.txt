# TruthLens backend dependencies - the lightweight set.
#
# Everything the backend needs to run EXCEPT PyTorch / PyTorch Geometric. This
# is what the Docker image installs by default, because PyTorch alone adds about
# 225 MB of resident memory and the free hosting tiers (Render: 512 MB) cannot
# hold it. The spread predictor falls back to plain arithmetic without it and
# returns identical results (see agents/spread_predictor.py).
#
# requirements.txt = this file + PyTorch Geometric, for a laptop or any host
# with roughly 1 GB+ of RAM.
#
# This file lists DIRECT dependencies only and lets pip resolve the rest.
# It must be saved as UTF-8: a UTF-16 file (what PowerShell's `>` produces)
# cannot be parsed by pip on Linux build hosts.
